# FlashAir 使用指南

本指南介绍 FlashAir SD 卡的基本用法，以及如何通过 FlashAir 应用访问卡片内容。

# 1. 启用 FlashAir 无线热点

将 FlashAir 插入相机并打开相机电源，无线热点即可启用。

# 2. 连接 FlashAir 无线热点

以智能手机为例，打开 Wi-Fi 设置，在网络列表中找到名称以“flashair”开头的热点并连接。初始密码为 12345678。

# 3. 访问 FlashAir 卡片内容

完成连接后，可以通过以下方式在智能手机上查看卡片内容。

# 3.1 通过浏览器访问

打开智能手机上的浏览器（例如 iPhone 上的 Safari），然后输入以下网址：

http://flashair (opens new window)

页面会显示 FlashAir 中的文件列表：

之后即可按照页面提示进行操作。

# 3.2 通过官方 FlashAir 应用访问

KIOXIA 提供了名为 FlashAir 的官方应用，可用于访问 FlashAir（iOS 版 (opens new window)、Android 版 (opens new window)）。以下是 iOS 版应用界面示例：

左侧是设备尚未连接 FlashAir 热点时的界面，并提供了连接指引。请注意，iOS 用户需要允许应用访问位置信息。

设备连接到热点并授予位置权限后，应用会显示右侧的文件列表。点击文件夹可浏览其中的文件；点击图片后会打开下载页面并显示进度，下载完成后即可查看图片。应用支持 JPG、PNG、HEIC 等常见图片格式，也支持多种 RAW 格式。

# 3.3 通过第三方应用 FlashAir Share 访问

有些用户可能不愿意为工具类应用授予位置权限。你也可以选择其他第三方应用，例如 FlashAir Share (opens new window)。

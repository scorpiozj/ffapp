# 常见问题

# FlashAir™ SD 卡和普通 SD 卡有什么不同？

FlashAir™ SD 卡符合 SD 协会制定的 SD 卡标准，因此可以用于其他标准 SD 卡适用的设备。此外，卡片还内置无线 LAN 芯片和通信天线，支持无线通信相关功能。

# FlashAir无线热点的初始密码是多少？

初始密码是: 12345678，并请注意密码长度至少是8位。

# FlashAir™ 无线热点突然消失，可能是什么原因？

通常有以下两种原因：

  1. 在FlashAir插入相机的情况下，当相机自动关机或进入待机状态，此时 FlashAir 无法继续从相机获取电源，无线信号也会随之中断。

**解决方法：**检查相机设置，延长进入待机状态前的时间，或关闭自动待机功能。

  1. FlashAir 的超时功能自动关闭了无线 LAN。长时间没有设备连接到 FlashAir 热点时，FlashAir 会自动关闭无线功能以节省电量。

**解决方法：**通过应用关闭超时功能，或延长超时时间。

# 除了数码相机，FlashAir 还能用于其他设备吗？

理论上，带有 SDHC™ 卡槽的设备都可以使用 FlashAir。

# FlashAir 的无线信号能覆盖多远？

覆盖距离取决于周围环境，可能只有几厘米，也可能最远达到约 10 米。

# FlashAir 工作模式

FlashAir 有 3 种工作模式。

# 什么是 AP 模式？

默认情况下，FlashAir 启动后会进入 AP（Access Point，无线接入点）模式。此时 FlashAir 会作为 Wi-Fi 热点，手机、电脑等客户端连接后即可访问卡片内容，但通常无法同时访问其他网络或互联网。

连接时，需要输入 FlashAir 热点的名称（SSID）和密码。此时可以将 FlashAir 理解为一个独立的无线网络。

# 什么是 Station 模式？

Station（STA）模式也称为客户端模式。在此模式下，先将 FlashAir 连接到现有的无线网络，再让手机、电脑等客户端也连接到同一个网络。之后，客户端可以通过设置的 FlashAir 标识符（APPNAME）访问 FlashAir：

http://APPNAME

http://APPNAME.local/ // 适用于 OS X

在此模式下，客户端可以同时访问 FlashAir 和该无线网络。如果该网络可以连接互联网，客户端也可以上网。

# 什么是 Internet-thru pass 模式？

Internet-thru pass 模式也称为互联网直通模式。在此模式下，FlashAir 同时作为 STA 客户端和 Wi-Fi 热点运行：FlashAir 先连接到已知 SSID 和密码的无线网络，客户端再像使用 AP 模式一样连接 FlashAir。

客户端可以同时访问 FlashAir 和上游无线网络。如果上游网络已连接互联网，客户端也可以通过 FlashAir 转发访问互联网。如果 FlashAir 无法连接到上游无线网络，则会切换到 AP 模式。

# FlashAir 工作模式比较

假设有一个可以访问互联网的无线网络，三种模式的区别如下：

模式 客户端连接对象 可访问互联网 连接上游网络失败时
AP FlashAir 否 -
STA 上游无线网络 是 -
Pass-Thru FlashAir 是 切换到 AP 模式

STA 模式和互联网直通模式的主要区别在于客户端连接的对象不同。STA 模式下，客户端需要连接上游无线网络并知道其密码；互联网直通模式下，客户端连接 FlashAir。请根据网络环境和安全需求选择合适的模式。

# 进阶用法

# 什么是 CONFIG 文件？

CONFIG 文件保存 FlashAir 的相关设置，例如 AP 模式下的无线接入点名称。该文件位于 /SD_WLAN 文件夹中，没有扩展名，文件名就是 CONFIG。它通常是隐藏文件；如需在电脑上查看或编辑，请先开启显示隐藏文件的选项。

编辑时请注意：

  1. 修改前先备份文件。
  2. 取出卡片前，先在电脑上安全弹出 FlashAir。

# 如何修改 FlashAir 无线局域网的密码？

可以通过以下 4 种方式修改无线密码：

  1. 使用官方 FlashAir 配置工具

打开软件，在“卡片设置”菜单中修改密码和无线接入点名称。密码至少需要 8 个字符。如果删除初始密码后没有设置新密码，连接到 FlashAir 的任何设备都可以访问卡片内容，请谨慎操作。

配置工具下载（来自官方网站）：

Windows Version Mac Version

  1. 通过浏览器修改（首次连接）

首次以 AP 模式连接 FlashAir 后，在浏览器地址栏中输入：

http://flashair (opens new window)

在打开的页面中选择相应菜单进行设置。

  1. 通过应用修改

可以使用官方或第三方应用修改密码。部分第三方应用需要先获取 FlashAir 主码（master code），才能进行修改。

  1. 修改 CONFIG 文件

将 FlashAir 插入电脑，打开卡片中的 CONFIG 文件，找到 APPNETWORKKEY 项，并将等号后的内容改为新密码。密码至少需要 8 个字符。保存文件后，请先在电脑上安全弹出 FlashAir，再取出卡片。

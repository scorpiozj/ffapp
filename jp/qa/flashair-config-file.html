# FlashAirのCONFIGファイル

CONFIGファイルにはFlashAirの設定が記録されています。内容を理解せずに変更すると、正常に動作しなくなるおそれがあります。

# CONFIGファイルとは

FlashAirの設定を記録したファイルです。APモードのSSIDなどの情報が含まれています。SDカード内のSD_WLANフォルダーにあり、拡張子は付きません（ファイル名はCONFIGで、CONFIG.txtではありません）。通常は隠しファイルとして扱われるため、パソコンで表示・編集するには、隠しファイルを表示する設定が必要です。 操作に慣れていない場合は、編集しないでください。

注意事項：

  1. 編集する前に、必ずファイルのバックアップを作成してください。
  2. カードを取り外す前に、パソコンの取り出し操作を行ってください。

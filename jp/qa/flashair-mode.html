# FlashAirの動作モード

FlashAirには3つの動作モードがあり、通常はAPモードで動作します。

# APモード

初期設定では、FlashAirはAP（アクセスポイント）モードで起動します。FlashAirがWi-Fiアクセスポイントとなり、パソコンやスマートフォンなどの端末を接続すると、カード内のデータにアクセスできます。このとき、端末からほかのネットワークやインターネットには接続できません。接続には、FlashAirのSSIDとパスワードが必要です。

# ステーションモード（STAモード）

ステーション（STA）モードでは、FlashAirを既存のWi-Fiネットワークに接続します。パソコンやスマートフォンなどの端末も同じネットワークに接続すると、設定したFlashAir名（APPNAME）でカードにアクセスできます。

http://APPNAME
http://APPNAME.local/  (OS Xの場合)

このモードでは、端末からFlashAirと接続先のWi-Fiネットワークを同時に利用できます。

# インターネットパススルーモード

インターネットパススルーモードでは、FlashAirが既存のWi-Fiネットワークに接続すると同時に、端末向けのアクセスポイントとしても動作します。端末はAPモードと同じ方法でFlashAirに接続し、カード内のデータにアクセスできます。FlashAirは端末と接続先ネットワークの間で通信を中継するため、接続先ネットワークがインターネットに接続されていれば、端末からFlashAirとインターネットの両方を利用できます。 接続先ネットワークに接続できない場合、FlashAirはAPモードで起動します。

# 各動作モードの比較

インターネットに接続できるWi-Fiネットワークがある場合、各モードの違いは次のとおりです。

モード 端末の接続先 インターネット接続 接続先が見つからない場合
AP FlashAir 不可 -
STA Wi-Fiネットワーク 可 -
パススルー FlashAir 可 APモードで起動

STAモードでは端末が既存のWi-Fiネットワークに接続するため、そのネットワークのパスワードが必要です。ネットワークのパスワードを知っている端末からFlashAirにアクセスできるため、利用者やアクセス範囲の管理にご注意ください。パススルーモードでは端末はFlashAirに接続します。

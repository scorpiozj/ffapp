# FlashAirのよくある質問

# FlashAir™と通常のSDカードにはどのような違いがありますか？

FlashAir™はSDアソシエーションが定めるSDカード規格に準拠しているため、通常のSDカードと同じように使用できます。さらに、無線LANチップと通信用アンテナを搭載しており、Wi-Fiでの通信にも対応しています。

# FlashAirのWi-Fiの初期パスワードは何ですか？

初期パスワードは 12345678 です。パスワードは8文字以上に設定してください。

# FlashAir™のWi-Fiアクセスポイントが突然見つからなくなったのはなぜですか？

主な原因は2つ考えられます。

  1. FlashAir™を挿入したカメラの電源が切れた、またはスタンバイ状態になった

カメラからFlashAir™への給電が止まると、無線LANも停止します。カメラの設定を確認し、スタンバイ状態になるまでの時間を延長するか、スタンバイ機能を無効にしてください。

  1. FlashAir™のタイムアウト機能が働いた

一定時間、Wi-Fiアクセスポイントに端末が接続しないと、省電力のため無線LAN機能が自動的に停止します。アプリでタイムアウト機能を無効にするか、停止までの時間を長めに設定してください。

詳しくはFlashAirに接続できないときをご覧ください。

# デジタルカメラ以外でもFlashAir™を使えますか？

SDHC™スロットを搭載した機器であれば、使用できる場合があります。

# Wi-Fiはどのくらいの距離まで届きますか？

通信距離は周囲の環境によって異なります。数cm程度の近距離から、最大約10mまで通信できます。

# FlashAirにはどのような動作モードがありますか？

FlashAirにはAPモード、ステーション（STA）モード、インターネットパススルーモードがあります。各モードの詳しい説明はFlashAirの動作モードをご覧ください。

# CONFIGファイルとは何ですか？

CONFIGファイルには、FlashAirのSSIDなどの設定が記録されています。カード内のSD_WLANフォルダーにあり、通常は隠しファイルとして扱われます。編集する前に必ずバックアップを作成し、カードを取り外す前にパソコンの取り出し操作を行ってください。

詳しくはFlashAirのCONFIGファイルをご覧ください。

# FlashAirのパスワードを変更するには？

公式設定ソフトウェア、ブラウザー、アプリ、またはCONFIGファイルから変更できます。詳しくはパスワードの変更方法をご覧ください。

# FlashAirの使い方ガイド

このガイドでは、FlashAir SDカードの基本的な使い方と、FlashAirアプリからカード内のファイルにアクセスする方法を説明します。

# 1. FlashAirのWi-Fiを有効にする

FlashAirカードをカメラに挿入し、カメラの電源を入れます。これでWi-Fiが有効になります。

# 2. FlashAirのWi-Fiに接続する

スマートフォンのWi-Fi設定を開き、一覧から「flashair」で始まるネットワークを選択して接続します。初期パスワードは 12345678 です。

# 3. FlashAir内のファイルを閲覧する

Wi-Fiに接続すると、スマートフォンからFlashAir内のファイルを閲覧できるようになります。

# 3.1 ブラウザーからアクセスする

スマートフォンのブラウザー（iPhoneの場合はSafariなど）を開き、次のURLを入力します。

http://flashair (opens new window)

FlashAirのファイル一覧が表示されたら、画面の案内に従って操作します。

# 3.2 公式アプリ「FlashAir」で閲覧する

キオクシア株式会社は、FlashAirにアクセスするための公式アプリ「FlashAir」を提供しています（iOS版 (opens new window)、Android版 (opens new window)）。iOS版の画面例を以下に示します。

左側はスマートフォンがFlashAirのWi-Fiに接続していないときの画面です。FlashAirへの接続方法も案内されます。iOSでは、アプリに位置情報へのアクセスを許可する必要があります。 FlashAirに接続し、位置情報へのアクセスを許可すると、右側のようにファイル一覧が表示されます。フォルダーを開いてファイルを確認でき、写真を選ぶとダウンロードが始まります。JPEG、PNG、HEICなどの画像形式や、多くのRAW形式に対応しています。

# 3.3 サードパーティ製アプリ「FlashAir Share」で閲覧する

位置情報へのアクセスが気になる場合は、別のアプリを利用する方法もあります。選択肢の一つがFlashAir Share (opens new window)です。

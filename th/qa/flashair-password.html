# รหัสผ่านของ FlashAir

บทความนี้อธิบายรหัสผ่านเริ่มต้นของ FlashAir และวิธีเปลี่ยนรหัสผ่านหลายวิธี

# รหัสผ่านเริ่มต้นของ Wi-Fi บน FlashAir คืออะไร

รหัสผ่านเริ่มต้นคือ 12345678

# วิธีเปลี่ยนรหัสผ่านของเครือข่ายไร้สายบน FlashAir

เปลี่ยนรหัสผ่านได้ 4 วิธีดังนี้

  1. ใช้โปรแกรมตั้งค่า FlashAir ทางการ

    เปิดโปรแกรมขึ้นมา แล้วไปที่เมนู "การตั้งค่าการ์ด" เพื่อเปลี่ยนรหัสผ่านและชื่อจุดกระจายสัญญาณ รหัสผ่านต้องมีความยาวอย่างน้อย 8 ตัวอักษร หากลบรหัสผ่านเริ่มต้นโดยไม่ตั้งรหัสใหม่ อุปกรณ์ใด ๆ ที่เชื่อมต่อกับ FlashAir ก็จะเข้าถึงข้อมูลบนการ์ดได้ โปรดใช้ความระมัดระวัง

    ดาวน์โหลดโปรแกรมตั้งค่า (จากเว็บไซต์ทางการ)

    เวอร์ชัน Windows

    เวอร์ชัน Mac

  2. ผ่านเบราว์เซอร์ (เมื่อเชื่อมต่อครั้งแรก)

    หลังเชื่อมต่อกับ FlashAir ในโหมด AP ครั้งแรก ให้กรอกที่อยู่ต่อไปนี้ในแถบเว็บ

    http://flashair (opens new window)

    จากนั้นเลือกเมนูที่ต้องการในหน้าที่เปิดขึ้นมาเพื่อตั้งค่า

  3. ผ่านแอป

    เปลี่ยนรหัสผ่านได้ทั้งจากแอปทางการหรือแอปจากผู้ให้บริการอื่น แต่บางแอปจำเป็นต้องทราบ master code ของ FlashAir ก่อนจึงจะเปลี่ยนได้

  4. แก้ไขไฟล์ CONFIG

    ใส่การ์ดลงคอมพิวเตอร์ เปิดไฟล์ CONFIG บนการ์ด จากนั้นหารายการ APPNETWORKKEY แล้วเปลี่ยนข้อความหลังเครื่องหมายเท่ากับเป็นรหัสผ่านใหม่ รหัสผ่านต้องมีความยาวอย่างน้อย 8 ตัวอักษร บันทึกไฟล์แล้วถอดการ์ดออกจากคอมพิวเตอร์อย่างปลอดภัยก่อนนำออกจากเครื่อง

# หัวข้อที่เกี่ยวข้อง

  • ไฟล์ CONFIG
  • ปัญหาการเชื่อมต่อ
  • โหมดการทำงาน

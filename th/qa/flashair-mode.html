# โหมดการทำงานของ FlashAir

FlashAir มีโหมดการทำงาน 3 โหมด โดยโหมด AP เป็นโหมดที่ใช้บ่อยที่สุด

# โหมด AP

โดยค่าเริ่มต้น เมื่อเปิดเครื่องการ์ดจะเข้าสู่โหมด AP (Access Point) ในโหมดนี้การ์ดจะทำหน้าที่เป็น จุดกระจายสัญญาณ Wi-Fi เมื่อสมาร์ตโฟนหรือคอมพิวเตอร์เชื่อมต่อแล้วก็เข้าถึงข้อมูลบนการ์ดได้ แต่จะไม่สามารถเข้าถึงเครือข่ายอื่นหรืออินเทอร์เน็ตพร้อมกันได้

การเชื่อมต่อต้องใช้ชื่อเครือข่าย (SSID) และรหัสผ่าน จึงมอง FlashAir ได้ว่าเป็นเครือข่ายไร้สายแยกต่างหาก

# โหมด Station

โหมด Station (STA) เรียกอีกอย่างว่าโหมดไคลเอนต์ ในโหมดนี้ให้เชื่อมต่อ FlashAir เข้ากับเครือข่ายไร้สายที่มีอยู่ก่อน จากนั้นให้สมาร์ตโฟนหรือคอมพิวเตอร์เข้ากับเครือข่ายเดียวกัน หลังจากนั้นจึงเข้าถึง FlashAir ได้ผ่านชื่อที่กำหนดไว้ (APPNAME)

http://APPNAME

http://APPNAME.local/ // สำหรับ OS X

ในโหมดนี้สามารถเข้าถึง FlashAir และเครือข่ายไร้สายได้พร้อมกัน หากเครือข่ายนั้นเชื่อมต่ออินเทอร์เน็ตได้ ก็สามารถใช้งานอินเทอร์เน็ตผ่านเครือข่ายดังกล่าวได้

# โหมด Internet-Thru-Pass

โหมด Internet-Thru-Pass เรียกอีกอย่างว่าโหมดส่งต่ออินเทอร์เน็ต ในโหมดนี้ FlashAir ทำงานเป็นทั้งไคลเอนต์ STA และจุดกระจายสัญญาณ Wi-Fi พร้อมกัน กล่าวคือ การ์ดเชื่อมต่อกับเครือข่ายไร้สายที่ทราบ SSID และรหัสผ่านก่อน จากนั้นอุปกรณ์ลูกค้าจึงเชื่อมต่อกับ FlashAir เหมือนกรณีโหมด AP

อุปกรณ์ลูกค้าเข้าถึง FlashAir และเครือข่ายด้านบนได้พร้อมกัน หากเครือข่ายด้านบนเชื่อมต่ออินเทอร์เน็ตอยู่ อุปกรณ์ลูกค้าจึงใช้งานอินเทอร์เน็ตผ่านการส่งต่อจาก FlashAir ได้ แต่หาก FlashAir เชื่อมต่อกับเครือข่ายด้านบนไม่สำเร็จ การ์ดจะสลับกลับไปเป็นโหมด AP

# เปรียบเทียบโหมดการทำงาน

กำหนดให้มีเครือข่ายไร้สายที่เข้าถึงอินเทอร์เน็ตได้ ความแตกต่างของทั้งสามโหมดคือ

โหมด อุปกรณ์ลูกค้าเชื่อมต่อกับ เข้าถึงอินเทอร์เน็ต เมื่อเชื่อมต่อเครือข่ายด้านบนไม่สำเร็จ
AP FlashAir ไม่ได้ -
STA เครือข่ายไร้สายด้านบน ได้ -
Pass-Thru FlashAir ได้ สลับเป็นโหมด AP

ความแตกต่างหลักระหว่างโหมด STA กับโหมดส่งต่ออินเทอร์เน็ต อยู่ที่อุปกรณ์ลูกค้าเชื่อมต่อกับอะไร ในโหมด STA อุปกรณ์ลูกค้าต้องเชื่อมต่อกับเครือข่ายด้านบนและต้องทราบรหัสผ่านของเครือข่ายนั้น ส่วนโหมดส่งต่ออินเทอร์เน็ต อุปกรณ์ลูกค้าเชื่อมต่อกับ FlashAir โปรดเลือกโหมดให้เหมาะกับสภาพแวดล้อมเครือข่ายและข้อกำหนดด้านความปลอดภัย

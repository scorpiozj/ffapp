# คู่มือใช้งาน FlashAir

คู่มือนี้อธิบายการใช้งานการ์ด SD ของ FlashAir ขั้นพื้นฐาน รวมถึงวิธีอ่านข้อมูลบนการ์ดผ่านแอป FlashAir

# 1. เปิดใช้งาน Wi-Fi ของ FlashAir

ใส่การ์ด FlashAir ลงกล้องแล้วเปิดเครื่อง ระบบ Wi-Fi จะทำงานทันที

# 2. เชื่อมต่อ Wi-Fi ของ FlashAir

เปิดการตั้งค่า Wi-Fi บนสมาร์ตโฟน ค้นหาเครือข่ายที่ชื่อขึ้นต้นด้วย "flashair" แล้วเชื่อมต่อ รหัสผ่านเริ่มต้นคือ 12345678

# 3. อ่านข้อมูลบนการ์ด

เมื่อเชื่อมต่อแล้ว สามารถดูข้อมูลบนการ์ดได้หลายวิธี

# 3.1 ผ่านเบราว์เซอร์

เปิดเบราว์เซอร์บนสมาร์ตโฟน (เช่น Safari บน iPhone) แล้วกรอกที่อยู่ต่อไปนี้

http://flashair (opens new window)

หน้าจอจะแสดงรายการไฟล์ที่เก็บอยู่ใน FlashAir

จากนั้นทำตามคำแนะนำบนหน้าจอได้เลย

# 3.2 ผ่านแอป FlashAir ทางการ

Kioxia มีแอปทางการชื่อ FlashAir สำหรับเข้าถึงข้อมูลบนการ์ด (iOS (opens new window), Android (opens new window)) ภาพต่อไปนี้เป็นตัวอย่างหน้าจอของแอปบน iOS

ด้านซ้ายคือหน้าจอช่วงที่ยังไม่ได้เชื่อมต่อ Wi-Fi ของ FlashAir พร้อมคำแนะนำการเชื่อมต่อ บน iOS แอปจำเป็นต้องได้รับสิทธิ์เข้าถึงตำแหน่ง

เมื่อเชื่อมต่อแล้วและอนุญาตให้เข้าถึงตำแหน่ง แอปจะแสดงรายการไฟล์ทางด้านขวา แตะที่โฟลเดอร์เพื่อดู เนื้อหาภายใน แตะที่รูปภาพเพื่อเปิดหน้าดาวน์โหลดพร้อมแถบความคืบหน้า เมื่อดาวน์โหลดเสร็จก็เปิดดูรูปได้ แอปรองรับไฟล์ภาพที่พบบ่อย เช่น JPG, PNG และ HEIC รวมถึงไฟล์ RAW หลายรูปแบบ

# 3.3 ผ่านแอปจากผู้ให้บริการอื่น FlashAir Share

ผู้ใช้บางคนไม่ต้องการให้สิทธิ์ตำแหน่งแก่แอปเครื่องมือ จึงเลือกใช้แอปอื่นแทนได้ เช่น FlashAir Share (opens new window)
